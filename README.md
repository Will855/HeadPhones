# HP Headphones Landing Page

Landing page moderna y altamente visual diseñada para mostrar unos auriculares de alta gama (HP Headphones).

## Características
- Diseño completamente responsive (Mobile First).
- Animaciones fluidas al hacer scroll.
- Secciones de características del producto, testimonios y llamado a la acción (CTA).
- Interfaz atractiva enfocada en la conversión y presentación del producto.

## Tecnologías
- HTML5
- CSS3 / Flexbox / CSS Grid
- JavaScript
